# Portrait Changer

Portrait Changer adds an Intel screen for changing the portraits, names, and genders of the main character, officers, administrators, and NPCs at the current planet or station.

Version 1.0.7a is an English translation and fork of the Chinese 1.0.7 release, which was developed from the original English 1.0.1 version by CY and Lukas04. This fork translates its newer features back into English and adds:

- every NPC registered at the market currently being visited;
- gender changes for every character whose portrait can be changed;

## Requirements

- Starsector 0.98a-RC8
- LunaLib

Nexerelin is optional at runtime but is required when compiling the mod. SimpleIndustryOptionProvider is optional and only enables the player-colony contact shortcut.

## Installation

1. Copy the `PortraitChanger` folder into Starsector's `mods` folder.
2. Enable **Portrait Changer** in the launcher.

## Usage

1. Open **Intel** and select **Change Portrait** under **Personal**.
2. Select a character at the top of the screen.
3. Select a portrait, or use **Random Portrait**.
4. Use **Apply Gender** to change the character's gender independently of their portrait.
5. Enter a name and select **Apply Name**, or use **Random Name** first.

To include local NPCs, enable **Current Planet/Station NPCs** in LunaLib settings and open the Intel screen while visiting their market. Available character groups and portrait pools can be configured in LunaLib settings. Add one custom random name per line to `optional_name_pool.txt`; an empty file uses names generated by the game.

Changing story-critical NPCs may interfere with scripts from other mods. Leave the **Important People** option disabled unless you know the affected content is safe.

## Build

From PowerShell, run:

```powershell
.\build.ps1 -StarsectorPath "<path to Starsector>"
```

The script uses Starsector's bundled JDK and normally finds LunaLib and Nexerelin under `mods`. Use `-LunaLibPath`, `-NexerelinJar`, `-ApiJar`, or `-JdkPath` for non-standard installations.

The first build downloads the pinned Kotlin 2.2.0 compiler into the ignored `build` folder. It then builds and verifies `jars\PortraitChanger.jar`.

The upstream 1.0.7 release did not include its current source. `lib\PortraitChanger-1.0.7-base.jar` therefore supplies its unchanged classes while `src\portrait_changer\PortraitChangerIntel.kt` is rebuilt.
